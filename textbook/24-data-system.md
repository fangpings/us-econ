# 24 数据获取与指标字典

[上一节](23-synthesis.md) · [目录](README.md) · [下一节](25-agent-monitoring.md)

## 学习目标

设计可追溯的数据结构；处理频率、时区、修订和缺失；把“指标名字”变成可实施的采集与计算规则。本节是系统设计教材，不表示已经部署采集程序。

## 1. 数据系统的五层

```text
原始来源 → 不可变原始快照 → 标准化记录 → 计算特征 → 报告
```

原始快照保存接口返回或文件，便于追溯；标准化记录统一字段和单位，但保留原始值；计算特征包括变动、增长率和分位；报告再使用这些经过校验的结果。

一个指标通常只有一个首选权威来源，可有备用来源。FRED 方便汇集，原发布机构负责定义和报告上下文。备用源与首选源不同步时要保留差异，不能无声拼接。

## 2. 每条观察值应保存什么

| 字段 | 含义 | 为什么需要 |
| --- | --- | --- |
| series_id | 数据源的唯一序列编号 | 防止同名不同口径 |
| observation_period | 观察日/月/季度 | 指标描述的时间 |
| published_at | 原始发布时刻，若可得 | 判断当时能否知道 |
| retrieved_at | 实际获取时刻 | 审计延迟与采集行为 |
| vintage / release_id | 数据版本/发布标识 | 保留历史修订 |
| raw_value / value | 原始值/标准化值 | 校验单位转换 |
| unit / frequency / seasonal_adjustment | 单位、频率、季调方式 | 防止口径混合 |
| source_url | 原始数据或报告链接 | 支撑引用 |
| quality_status | 正常、未发布、延迟、缺失、错误等 | 防止把缺失当成零 |

如果来源只有发布日期，没有时刻，就保存未知，不要伪造 08:30。ALFRED 等历史版本日期也不能自动提供每次日内可用时刻。

## 3. 指标定义与观察值分开

指标注册表描述“如何获取与解释”；观察表描述“某个版本的某个时点是多少”。注册表可以如下：

```yaml
name: 10年期美国国债常数期限收益率
source: FRED
series_id: DGS10
native_unit: percent
frequency: daily
seasonal_adjustment: not_seasonally_adjusted
features:
  - change_bp_vs_previous_valid_observation
  - change_bp_over_5_valid_intervals
  - change_bp_over_20_valid_intervals
missing_policy: retain_missing
calendar: source_calendar
interpretation: 收益率而非债券价格；并非某只券的逐笔报价
```

它是说明格式，不是已经测试的采集配置。更多候选编号见[附录 A](appendix-a-indicators.md)。接入前读取元数据，验证单位和频率；不能靠名字猜。

## 4. 不同频率怎样共存

每日仪表盘可以显示最新月度失业率，但必须同时显示观察月和最后发布日期。显示层可以沿用最新已知值，统计计算层不能把这个月度数复制二十次再计算“日波动率”。

周度准备金也不能靠插值变成真实日值。SOFR 与 EFFR 比较应匹配同一交易日；政策管理利率应按当日有效值匹配，而不是按你抓取它的日期。

美国东部时间要用 `America/New_York` 等时区规则处理夏令时，不可全年固定为 UTC−5。日报采用统一的信息截止时刻，并注明各数据真实观察日。

## 5. 哪些检查适合自动完成

检查重复记录、时间倒序、无法解析值、单位变化、意外历史断裂和发布后仍缺失。保留数据源的缺失符号含义，例如点号并非零。

异常值应先标记而非自动删除：危机期间的极端值可能正是需要研究的现象。周末没有市场报价通常是正常；月度数据超过预定发布时间仍未更新则可能是延迟。陈旧判断依赖发布日历和来源延迟，不能全用固定“七天”。

准备金常以百万美元给出，ON RRP 可用十亿美元；相加前要统一。余额对齐还需一致的时点或平均口径，这比单位转换更容易被忽略。

## 6. 历史比较怎样避免伪精确

“历史第 95 分位”必须注明样本窗口、观察数、频率、水平还是变化量。三年 HY 数据不能支持“过去二十年第 95 分位”。制度改变后，跨全历史的利差分位也可能失去可比性。

Z 分数是 `(X−均值)/标准差`，表示相对样本的标准化偏离，不自动对应正态分布概率。金融序列常有厚尾和波动变化，超过两倍标准差不等于固定危机概率。

## 监控实践

建议第一版先做十余条核心序列的端到端流程，再扩展[附录 A](appendix-a-indicators.md)的核心集合。采集成功率、版本保存和正确对齐，比一次接入上百条但口径不明的指标更重要。

## 练习

1. FRED 今日补充了上周某日数值，应把经济变化记在今天还是观察日？
2. 只有三年样本，可以输出十年历史分位吗？
3. 月度指标每天数值不变，应输出“今日变化 0”吗？

<details>
<summary>参考答案</summary>

1. 数值属于观察日，信息可用性属于今日获取/发布记录；二者都要保存。
2. 不能，只能报告现有窗口分位或样本不足。
3. 应写“今日无新发布”，与真实测得的零变化不同。

</details>
