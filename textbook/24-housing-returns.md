# 24 买房、租房与住房持有回报

[上一章](23-housing-market.md) · [目录](./) · [下一章](25-mortgages-households.md)


> 第 24 章，2026-10-03。以下金额均为教学假设，单位美元；不是投资、税务或购房建议。先读住房价格与库存，再读本章；下一章把贷款加入同一套账。

## 学习主线：房价上涨，不等于房主赚了同样比例

一套 300,000 的房子一年后卖 309,000，价格涨了 3%。业主是否获得 3% 回报？需要知道买卖费用、租金、维修和税费。如果是自住，还要区分居住服务与实际收到的现金。本章先不借款，把资产本身看清楚，再比较租住与购买。

读完应能列住房现金流、复算净租金与持有期回报、比较不同退出日期，并解释为什么“租金比月供低”不能单独决定选择。机会成本指选择本方案后放弃的替代方案收益；它不是一定要付给某个人的一张账单。

## 1. 房屋提供两种不同东西

房屋可以提供居住服务，也可以作为可转售资产。出租时，服务通过租约换来租金；自住时，家庭自己消费服务，没有向自己支付现金。房屋市场价是购买未来服务和转售机会的资产价格，不是本期服务价格。

例如同一套房月租 2,000，购价 300,000。年租金与价格之比是 `24,000/300,000=8%`，称为毛租金收益率。它没有扣空置和费用，也没有包含价格变化，因此既不是净回报，也不能直接与一张债券的到期收益率比较。

自住家庭可用相似住房租金估计所消费的服务，但估计的服务不是能付房贷的现金。宏观核算中的自有住房服务也与房屋成交价不同；[BEA 对住房服务的说明](https://www.bea.gov/help/faq/488)解释为何自住服务进入经济核算，不能据此把虚拟租金当作到账收入。

## 2. 先经营一年，再决定卖不卖

假设购价 300,000，购买交易费用 6,000，全部现金支付。房屋没有新增装修资本开支，一年后以 309,000 出售，出售费用为成交额 5%，即 15,450。出租期间资料如下：

| 项目 | 金额 | 为什么这样处理 |
| --- | ---: | --- |
| 满租合同租金 | 24,000 | 2,000 × 12，不代表全部收到了 |
| 空置及无法收回租金 | −2,000 | 不可把没有收到的金额当收入 |
| 房产税 | −3,600 | 本例实际付出的持有费用 |
| 保险 | −1,200 | 保障合同成本，不是房价的一部分 |
| 日常维修 | −2,000 | 本例维护现有状态，不增加新面积 |
| 管理费用 | −1,200 | 外包管理的现金成本 |
| 净经营现金 | 14,000 | 实收 22,000 减上述费用 8,000 |

本例把净经营现金定义为融资前、所得税前的实际净租金现金。不要与所有财务报表中名为 NOI 的数字自动等同：业主协会费用、资本性支出准备和其他项目是否包含，要看来源定义。

```text
初始投入 = 300,000 + 6,000 = 306,000
出售净收入 = 309,000 − 15,450 = 293,550
一年持有损益 = 14,000 + 293,550 − 306,000 = 1,550
持有期回报 = 1,550 / 306,000 ≈ 0.51%
```

房价涨 3%，投资者所得税前持有回报只有约 0.51%。不是费用“改变了指数”，而是指数与个人净现金回报回答不同问题。本例一年末收取净租金，若现金分布在月度或追加投资很多，应把每笔金额和日期逐项列出，不能随意把各年的百分比相加。

## 3. 费用、资本投入和偿还本金不是同一类项目

维修屋顶可能维持房屋状态，也可能延长寿命；新增一间卧室可能增加资产质量。经济分析先问是否改变资产提供服务的能力，再记现金，不要仅凭发票名称判断税务处理。税法折旧、抵扣和出售计税基础另有制度，本章不设一个适用于所有人的税率。

假设持有中途再花 20,000 扩建，卖价变为 330,000。不能说从 300,000 到 330,000 全是“同质房价上涨 10%”，也不能在收益分母中忘掉追加投入。正确起点是初始现金 −306,000、中途现金 −20,000、各期租金、最后出售净收入；如算单一持有期收益，至少要清楚标明没有处理现金时间差。精细比较用净现值。

贷款本金的偿还又不同：它减少现金，同时减少负债，通常不是当期经济费用；利息则是借款成本。但家庭付月供时，本金与利息都需要现金。不能因本金不是费用就把它从现金预算中删掉。这是下一章家庭资产负债表的入口。

## 4. 用同一终点比较买房与租房

公平比较需要相似居住服务、相同持有时间、相同起始财富，并处理每年现金差额的投资或融资。把租金和房贷月供单独摆在一起，没有处理首付、退出价值和风险。

先做无贷款、一年期限、年末支付租金的简化模型。可买房 300,000，买入费用 6,000，持有支出 8,000；也可租同样房屋，年租 24,000。可用低风险替代收益率假设为 4%，卖房费用 5%。忽略所得税，两方案初始可支配资金相同。

从租房方案改成买房，增量现金流是：今天支付 306,000；一年后不再支付 24,000 租金，但支付 8,000 持有成本，并获得出售净收入 `0.95P`，P 为一年后出售价格。因此：

```text
买房相对租房的净现值 = −306,000 + (24,000 − 8,000 + 0.95P)/1.04
令净现值为零：0.95P = 306,000×1.04 − 16,000 = 302,240
盈亏平衡出售价格 P ≈ 318,147.37
```

这个模型要求约 6.05% 的价格上涨才能使买房相对于租房达到所设的 4% 机会成本标准。它不是房价预测，更不是普遍的买租分界线；它告诉你，短持有期和交易费用能显著改变比较。

如果打算住十年，交易费分摊到更多年份，租金与持有费用也会变化；如果替代收益率变高，首付款机会成本上升。自住还带来稳定居住、装修自主权等非现金价值，也可能降低搬迁灵活性。应把这些偏好单列，而不是伪装成精确金融收益率。

## 5. 房价收入比、租售比与负担能力

房价收入比把房屋价格与某一口径年收入相除。例如 300,000/75,000=4 倍。它便于描述，但没有回答首付、税费、贷款条件和收入分布。同一个 4 倍，在贷款利率 3% 与 7% 时月供不同；家庭收入中位数与实际购房者收入也不同。

租售比下降可能来自房价上涨快于租金，也可能来自租金下降。不能未经检查就断言泡沫：折现率、预期租金增长、供给、税费与风险都影响资产价格。相同租金若维护成本更高，其可支持的净现金流更低。

比较城市时，必须匹配房型、面积、区位和日期。用市中心小户型租金除以郊区独栋价格，得到的比率没有清晰对象。价格指数控制部分质量变化，实际家庭买的却是一套特定住房；全国指数不会替你完成物业状况调查。

## 6. 带读原始购房文件：报价之外还有什么？

打开 CFPB 的 [Closing Disclosure 交割披露解释页](https://www.consumerfinance.gov/owning-a-home/closing-disclosure/)，该页是官方样表带读，不是你的贷款合同。按以下顺序读，不必先背所有费用术语：

1. 先确认交易、房产和借款人，查看最终贷款条件。
2. 分开看月度付款和交割时现金；能付月供不代表已有足够交割资金。
3. 找出贷款费用、其他交易费用、预付项目和托管安排。预先放入税费托管账户的现金是资金占用，不应在未来支付税费时重复记成本。
4. 对照先前 Loan Estimate，记录变化，并查是谁支付、是否融资进入本金。

文件的作用是辨认合同现金流。本章算例的 6,000 买入费和 8,000 年持有费是自编金额，不来自样表，不可以把它们当美国统一收费标准。贷款利息与 APR 的比较留给按揭章。

## 7. 练习：把收益和现金分开

### 练习一：房价没涨是否必然亏钱？

全现金买房价格 200,000，买入费用 4,000，一年净经营现金 12,000，按原价出售，出售费用 8,000。求持有期收益，并说明为什么不能只看房价。

<details><summary>参考答案</summary>

初始投入 204,000，最终出售净收入 192,000，加经营现金 12,000 正好 204,000，所得税前名义回报为零。若考虑通胀和资金机会成本，零名义收益未必合意；价格没涨并不单独决定结果。

</details>

### 练习二：敏感性与验证

把正文买租比较的未来出售价格设为 300,000，求买房相对净现值。然后说明至少三个可改变结论的假设。

<details><summary>参考答案</summary>

`−306,000+(16,000+285,000)/1.04≈−16,576.92`。在给定模型下买房财务结果较差。租金、持有期、未来价格、费用、机会成本和税务均能改变比较；不能把未观察到的房价上涨当确定补偿。租住与购买的住房质量不同也会使比较失效。

</details>

### 练习三：审计一个“8% 回报”广告

对方只提供购价 300,000、月租 2,000。列出你需要索取的资料，并写一段不超过 150 字的判断。

<details><summary>参考答案与标准</summary>

需要实际收租、空置、税险、维修、管理和协会费用、近期大修、买卖费用、融资与持有期限。合格判断：“8% 是满租毛租金/购价，不是净回报；尚缺现金支出与价格风险，无法确定持有收益。”资料应能改变计算，而非泛泛要求“更多信息”。

</details>

自住服务、经营现金、融资现金和退出价值区分清楚后，才能把按揭加入模型。不要在加杠杆之前就把资产回报算错。
