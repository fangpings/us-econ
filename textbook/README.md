# 美国宏观经济与金融体系：从指标形成到市场理解

本教材面向没有经济金融专业基础的大学生。只需百分比、四则运算和简单代数；公式从具体例子讲起。目标不是记住缩写，而是能追溯数字的形成过程、完成计算、阅读原始资料，并用证据比较不同解释。

## 如何学习

按编号阅读，每章分为理解机制、复算案例、独立练习三轮。较长章节可分两三次完成。先做练习再展开答案；遇到市场指标，沿着参与者、合同、交易、清算和统计加工回溯，而不是只背“上升利好谁”。全书假设数字均用于教学，只有明确标注来源和日期的材料才是历史事实，不代表当前行情。

## 分阶段检查自己是否真的学会

- 01—10：给一份原始发布标注对象、频率、单位、初值和修订，复算一个增速，区分价格与数量。
- 11—22：画出一笔融资的双方账本，解释谁决定合同、谁获得现金、谁最终承担损失；区分政策利率、国债收益率和信用利差。
- 23—37：跟踪一项资产从取得、融资、交易到履约的全过程，计算回报与现金缺口，不把净值、收益和流动性混为一谈。
- 38—42：按信息截止时刻重建证据，提出竞争性解释，写出可被后续事实修改的报告。
