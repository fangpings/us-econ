# 美国宏观经济：从指标理解到每日监控

这是一套面向大学阶段初学者的自学教材。你不需要先修金融学或编程课程，但应当会使用百分比、四则运算和简单代数。遇到公式时，先理解各项的含义，再代入例子计算。

学习目标不是记住最多的指标，而是形成三种能力：解释一个数字究竟测量什么；用多个指标比较不同解释；把分析过程变成可复核的每日监控。

## 如何使用

正文采用学习目标、概念解释、算例或情景、监控提示与练习的结构，附参考答案和原始资料；最后一节是完整毕业项目。先独立做题，再打开答案；读完能复述概念，不等于能在数据里正确应用。

建议每周学习两节，每节用一次阅读和一次复盘完成，全程约十二周。难点章节可以拆成两次。第 15—17 节涉及你特别关心的准备金、回购和美债市场，但其前置知识在第 11—14 节。

全书数值案例除明确注明历史事实外，均为**教学假设**，不描述当前行情。教材编写日期为 2026-09-15。制度、数据可用性、指标基期、API 和发布时间可能变化，运行监控时应重新核验官方元数据与发布日历。

这是一门指标分析与研究方法课程，不代替完整的宏观经济学、计量经济学或固定收益定价课程。读完应能独立写出有证据和边界的宏观简报；严谨的因果识别和复杂衍生品定价属于后续学习。

## 四个阶段检查点

1. 完成第 08 节：写出一页增长诊断，解释消费、就业、投资和供给之间的关系。
2. 完成第 13 节：解释同样的名义收益率上涨为什么可以有不同含义。
3. 完成第 20 节：用账户变化推演财政、准备金与融资，再连接信用与资产价格。
4. 完成第 24 节：交付一份带数据日期、修订记录、替代解释和验证条件的简报。

如果你不能指出“什么新证据会使自己改变判断”，说明当前结论还不够清晰。
