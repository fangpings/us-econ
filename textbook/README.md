# 美国宏观经济：从指标形成到市场理解

这是一套面向大学阶段初学者的自学教材。你不需要先修金融学或编程课程，但应当会使用百分比、四则运算和简单代数。遇到公式时，先理解各项的含义，再代入例子计算。

学习目标不是记住最多的指标，而是形成三种能力：解释一个数字如何形成、究竟测量什么；用多个指标比较不同解释；把经济变化与政策、融资和资产价格联系起来。

## 如何使用

正文采用学习目标、概念解释、算例或情景、阅读提示与练习的结构，附参考答案和原始资料。先独立做题，再打开答案；读完能复述概念，不等于能在数据里正确应用。

建议每周学习一至两章，每章用阅读、算例和复盘分次完成，实际按学习进度调整。当前目录安排 26 章，新第 23—26 章已于 2026-09-26 完成扩写，含形成机制、算例、原始资料阅读及带推理的练习答案。第 15—17 章涉及准备金、回购和美债市场，其前置知识在第 11—14 章。

第 20—21 章为外汇与全球美元模块，第 22—25 章为独立股市模块，第 26 章为商品与跨资产联系，采用连续编号。股票模块依次讲交易与指数、企业盈利、估值和资金与期权，再在商品章完成跨资产综合应用。

**范围调整（2026-09-26）：**原第 23—26 章“证据组合、数据系统、agent 日报、毕业项目”已删除；相同编号现用于不同的新主题。先完成教材，再单独立项开发每日报告 agent，不把系统实现混入本轮教材重写。附录中的数据入口和记录模板仍可作为学习参考。

全书数值案例除明确注明历史事实外，均为**教学假设**，不描述当前行情。教材编写日期为 2026-09-15。制度、数据可用性、指标基期、API 和发布时间可能变化，运行监控时应重新核验官方元数据与发布日历。

这是一门指标分析与研究方法课程，不代替完整的宏观经济学、计量经济学或固定收益定价课程。读完应能独立写出有证据和边界的宏观简报；严谨的因果识别和复杂衍生品定价属于后续学习。

## 四个阶段检查点

1. 完成第 08 节：写出一页增长诊断，解释消费、就业、投资和供给之间的关系。
2. 完成第 13 节：解释同样的名义收益率上涨为什么可以有不同含义。
3. 完成第 21 章：用账户变化推演财政、准备金与境内外融资，连接信用与汇率。
4. 完成股市及商品模块后：用指数构成、企业盈利、估值和交易机制解释市场分化，再与股债汇及商品证据相互核对。每日报告 agent 留到教材完成后的独立开发阶段。

如果你不能指出“什么新证据会使自己改变判断”，说明当前结论还不够清晰。
