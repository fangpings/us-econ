# 附录 B：公式与术语速查

[返回目录](./)

本附录用于复习；理解机制请回到对应章节。公式中的增速若参与乘除与乘方，使用小数而非百分数，例如 3%写为 0.03。

## 1. 公式

| 用途 | 公式 | 条件与单位 |
| --- | --- | --- |
| 净资产 | 资产−负债 | 同一主体与时点 |
| 环比 | `X_t/X_(t−1)−1` | 同一频率 |
| 月度同比 | `X_t/X_(t−12)−1` | 月度水平；不直接套在负值或过零序列 |
| 月环比年化 | `(1+月增速)^12−1` | 季调、仅换算速度 |
| 季环比年化 | `(1+季增速)^4−1` | 非同比 |
| 三个月年化 | `(X_t/X_(t−3))^4−1` | 月度水平 |
| 实际增速 | `(1+名义增速)/(1+价格增速)−1` | 价格口径匹配 |
| 基点变化 | `(本期百分数−前期百分数)×100` | 如 4.25−4.00 得 25bp |
| 失业率 | `失业人数/(就业+失业人数)` | 不能把非劳动力放进分母 |
| 单位劳动成本 | 每小时劳动报酬/每小时产出 | 对应同一部门 |
| 债券价格敏感性 | `ΔP/P≈−修正久期×Δy` | Δy 用小数、小幅移动近似 |
| 2s10s | 10Y−2Y | 说明结果是百分点或 bp |
| 简化预期信用损失 | 违约概率×违约损失率 | 不等于完整风险利差 |
| 利息覆盖率 | EBIT/利息支出 | 不同分析口径需注明 |
| 股价分解 | EPS×P/E | 同一盈利口径，非正盈利需谨慎 |
| Z 分数 | `(X−样本均值)/样本标准差` | 不自动对应危机概率 |

同比对正值价格指数通常合适，但若油价、利润或其他序列跨过零，百分比变化可能失去通常含义；可改报告绝对变化并说明原因。

## 5. 住房、合同与研究工作流

| 名称或公式 | 含义与适用边界 | 正文 |
| --- | --- | --- |

## 6. 第二轮之后的专题

基础课程结束后，可进一步学习多曲线定价与数值方法、最便宜可交割券及交割期权、完整银行资本与流动性监管、抵押品链条网络、保险精算、结构化产品损失模型和严谨的因果识别。正文已提供相关基础，不意味着已经覆盖专业建模和法律判断的全部要求。

旧资料中的 LIBOR、FRA−OIS 等须结合历史制度阅读。不要直接把已退出原基准体系的指标复制成当前默认监控；新基准的利差未必具有相同的信用含义。
