# 附录 D：官方资料阅读路线

[返回目录](README.md)

正文提供了理解框架。遇到定义、修订或数据口径问题，回到发布机构的方法与元数据。以下不是要求一次读完的书单；每轮只完成对应任务。

## 1. 实体经济：先读定义，再读一份发布

| 资料 | 什么时候读 | 需要找到的答案 |
| --- | --- | --- |
| [BEA 国民账户入门](https://www.bea.gov/resources/methodologies/measuring-the-economy) | 第 01、04 节后 | GDP 的边界，生产、收入与支出的关系 |
| [BEA GDP](https://www.bea.gov/data/gdp/gross-domestic-product) | 第 04 节后 | 当期增长贡献、实际与名义、修订 |
| [BEA 消费支出](https://www.bea.gov/data/consumer-spending/main) | 第 05 节后 | PCE 量与价格，商品与服务 |
| [BEA 个人收入](https://www.bea.gov/data/income-saving/personal-income) | 第 05 节后 | 可支配收入、个人支出、储蓄 |
| [BLS 家庭与企业调查比较](https://www.bls.gov/web/empsit/ces_cps_trends.htm) | 第 06 节后 | 为什么岗位与人数不同 |
| [BLS JOLTS](https://www.bls.gov/jlt/) | 第 06 节后 | 职位空缺、招聘、离职的存量/流量定义 |
| [美联储工业生产 G.17](https://www.federalreserve.gov/releases/g17/) | 第 07 节后 | 总指数与制造业、公用事业分项 |
| [Census 新住宅建设](https://www.census.gov/construction/nrc/index.html) | 第 07 节后 | 许可、开工、竣工与 SAAR |
| [BLS 生产率](https://www.bls.gov/productivity/) | 第 08 节后 | 产出、工时、劳动报酬与 ULC |

阅读练习：任选报告，先不看媒体，抄出标题数字、一个重要分项、一个修订和一个方法限制，再阅读媒体比较遗漏了什么。

## 2. 通胀：核对篮子、权重和住房

| 资料 | 需要找到的答案 |
| --- | --- |
| [BLS CPI FAQ](https://www.bls.gov/cpi/questions-and-answers.htm) | CPI 覆盖谁、什么不包含、季调如何使用 |
| [BEA CPI 与 PCE 差异](https://www.bea.gov/help/faq/555) | 范围、权重、公式和其他差异 |
| [BLS 租金与 OER](https://www.bls.gov/cpi/factsheets/owners-equivalent-rent-and-rent.htm) | 权重资料与价格变化资料如何区分 |
| [Fed 对通胀的解释](https://www.federalreserve.gov/faqs/economy_14419.htm) | 2%目标对应哪个价格指标 |
| [纽约联储 SCE](https://www.newyorkfed.org/microeconomics/sce) | 预期期限、人群与统计方式 |
| [纽约联储 GSCPI](https://www.newyorkfed.org/research/policy/gscpi) | 供应链指标构成及标准化含义 |

阅读练习：解释 CPI 与 PCE 某月背离的可能来源，并指出你还需要哪些分项才能实际验证。不要假定全部差异都来自住房。

| 资料 | 需要找到的答案 |

| [纽约联储期限溢价](https://www.newyorkfed.org/research/data_indicators/term-premia-tabs) | 观测利率与模型分解的差别 |

阅读练习：找一份 H.4.1，把周均和周三时点列分开标记，再尝试核对一组同口径资产负债。不要先从社交媒体“净流动性图”倒推会计关系。

## 4. 信用与金融条件

| 资料 | 需要找到的答案 |
| --- | --- |
| [H.8 银行资产负债](https://www.federalreserve.gov/releases/h8/) | 贷款类别、存款、修订与重分类 |
| [SLOOS](https://www.federalreserve.gov/data/sloos.htm) | 标准与需求的各自变化 |
| [纽约联储家庭债务报告](https://www.newyorkfed.org/microeconomics/hhdc/background) | 样本、债务类别和逾期定义 |
| [ICE BofA HY OAS 元数据](https://fred.stlouisfed.org/series/BAMLH0A0HYM2) | 指数构成、单位、历史与使用限制 |
| [芝加哥联储 NFCI](https://www.chicagofed.org/research/data/nfci/current-data) | 金融条件指数的成分和解释 |

阅读练习：找一个贷款余额走弱的时期，用 SLOOS 检查供给与需求，承认调查无法完全解决的归因问题。

## 5. 数据与版本

| 资料 | 需要找到的答案 |
| --- | --- |
| [FRED API](https://fred.stlouisfed.org/docs/api/fred/) | 序列元数据、观察值、发布与历史版本 |
| [BLS API](https://www.bls.gov/developers/) | 请求、注册、频率和使用限制 |
| [纽约联储 Markets API](https://markets.newyorkfed.org/static/docs/markets-api.html) | 参考利率与市场操作数据的实际字段 |
| [BLS 日历](https://www.bls.gov/schedule/) | 实际发布日和时区 |
| [BEA 日历](https://www.bea.gov/news/schedule) | 发布、修订与假日安排 |

阅读练习：选一条序列，记录来源定义与元数据，再取得两个版本。说明“观察值改变”“历史值修订”和“数据源今天补录”如何区分。

## 6. 资料发生变化时

网页打不开不代表指标不存在，可能是链接迁移、访问限制或临时故障。回到机构首页搜索原始名称，核对编号与定义；不要用名字相近的序列无声替代。

本书核查了关键定义、部分元数据和重要制度变化，未执行所有 API 的在线集成测试，也未建立付费数据订阅。真正接入每日监控时，应再核查发布规则、可用历史、访问权限和方法更新，并给指标注册表记录核验日期。
